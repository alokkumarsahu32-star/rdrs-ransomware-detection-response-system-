Set Up Your RDRS Agent

Without installing and connecting the RDRS Agent on your Windows computer, you cannot scan folders stored on that computer.

  1. Download the Agent
    Download the Windows installer using the button below.
  2. Install the Agent
    Open the downloaded installer and follow the setup instructions.
  3. Enroll Your Device
    Return to this dashboard and click Enroll Device to generate a one-time enrollment code.
  4. Connect the Agent
    Open the installed agent and enter the enrollment code if prompted. Keep the agent running.
  5. Scan Your Folder
    Click Select Folder & Scan, choose a folder on your computer, and wait for the results.

Only scan folders you own or are authorized to inspect.
